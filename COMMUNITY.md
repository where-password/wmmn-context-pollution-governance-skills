# Community

Questions, reproducible failures, and narrow feature requests are welcome through GitHub Issues.

When sharing a case, remove:

- API keys and Authorization headers;
- `.env` or secret files;
- private conversation content and private URLs;
- local absolute paths when not needed;
- database and Milvus credentials;
- production collection or alias names.

A good report states the Skill version, command, expected result, actual result, and a synthetic reduction. This project values evidence over generic feature counts.
